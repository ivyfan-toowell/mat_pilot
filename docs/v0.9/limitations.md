# V0.9 科研与工程局限

1. 新版目前以 optical_band_gap eV 为唯一物性；理论带隙另由 Materials Project 查询，不混成一列。
2. 原文定位支持已解析文本块的页码和行号。复杂表格/图像、跨页合并单元格、图中数值数字化不可靠或未实现。
3. 新版提取对样品和数值关联要求保守；表格中条件与性能位于不同块时，可能拒绝本来正确的数据，形成漏召回。
4. 数据模型为 JSONB 观察记录，尚无完整的组成—工艺—测量—物性规范化本体与可搜索工艺步骤历史。
5. 部分审核者身份由 API 请求文本提供，适合本机演示，不能用于受监管科研审计。
6. 数据审核不会证明物理解释正确。某两组实验数据可比较，也不能证明工艺导致某个带隙变化。
7. 现有异步 JobWorker 为单进程线程池，崩溃后不自动恢复执行。报告生成尚无独立后台归档任务。
8. CI 在合成 fixture 和显式 mock 下运行，不能证明真实模型、论文与数据库的端到端正确性。
9. 本轮未完成多篇真实论文独立人工标注与效率基线，不能声称科研准确率提升或节省时间比例。
10. 本轮不引入 Neo4j、OCR、DFT、自动实验、通用材料属性知识图谱。
